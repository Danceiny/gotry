# GoTry 使用指南

> 你现在就能用。不需要安装任何东西——服务已经在跑了。

## 现在就能试

打开浏览器,访问 **http://127.0.0.1:4080**

你会看到 GoTry 的界面(深蓝主题),左边三个导航:
- **对话** — 跟 GoTry 聊你的旅行计划
- **下一次出发** — 存放这次去不了的目的地(带成行条件)
- **动机画像** — 你的工作窗口、预算档、同行人

在对话框里试试这些(直接复制粘贴):

### 试一试:洱海发呆(候选判定)

```
我想去洱海边发呆,就这周末,我在上海,预算3000,别让我早起。年假了不用办公,还没订任何东西。
```

你会看到:
- **大理·洱海:现在不行** — 2 天装不下,进了「下一次出发」(需要 5 天/¥4950/春秋最佳)
- **千岛湖:可行** — 06:35 起床(卡着你的"别早起"底线)/84% 精力/¥1002
- **苏州·太湖:可行** — 更便宜(¥755)但匹配度低
- 两道选择题让你定

### 试一试:带爸妈去云南(同伴感知)

```
带爸妈去云南玩5天,深圳出发,预算15000三人。请年假了不用办公,还没订。爸爸65有轻度高血压,别太累。直接给方案。
```

引擎会感知到"爸妈+高血压":
- 不上玉龙雪山(4506m 绝对禁止)
- 海拔递减结构:丽江 2400m 在前(适应期)→ 大理 1976m 在后(安全垫)
- 每日步行 ≤4 小时
- 起床 ≥7:00(老人生物钟)

### 试一试:海外远程办公(工作窗口)

```
我在迪拜工作,UTC+4上午10点到晚上7点。下个月想飞普吉岛两周,女朋友在那边等我。帮我规划。
```

工作窗口自动换算成当地时间(普吉 13:00-22:00),成为硬约束——周五晚班机会被排除(你还在上班),只推周六早班。

## 你看到的每个数字

| 数字 | 来源 | 含义 |
|---|---|---|
| ¥1002 | Z3 求解器 | 千岛湖方案的门到门全成本(机票+接驳+住宿) |
| 06:35 起床 | 引擎计算 | 从家到机场+提前值机+班期倒推 |
| 84% 到达精力 | 精力模型 | 100 − 起床惩罚 − 接驳消耗(不是拍的,是公式) |
| 门到门 3h52m | 时区感知 | 含真实飞行时长(不是表观时差) |
| [骨架:openflights] | OpenFlights | 航线通航性验证(免费公开数据) |
| [静态包:估算] | 人工调研 | 价格是估算,预订前需核实 |

## 为什么它「懂事儿」

你之前可能试过 ChatGPT/Kimi/其他 AI 旅行规划,它们的问题是:
- **不问你**就直接出方案(你的工作时间/已订资源/父母身体它们不知道要问)
- **编造**班次和价格(数据不在模型里,它就瞎编)
- **重排**而不是修改(你改一个日期,它把整个行程推倒重来)

GoTry 的每个推荐后面有数学求解器(Z3)在算「可行性」——不是 AI 觉得不错,是**算过**的。

## 在 dsh 里用(进阶)

如果你想用更强大的 agent 能力(多步推理/工具链/会话管理):

打开 **http://127.0.0.1:3080** — 这是 DeepSeek Harness 的 web 界面,加载了 GoTry 的全部工具和人格。

功能一样,但 agent 能力更强(可以做多步推理、自主调用工具、长会话)。

## 常见问题

**Q: 服务挂了怎么办?**
```bash
cd ~/work/gotry && ./gotry shell    # 重新启动
```

**Q: 换了 API key?**
编辑 `~/work/gotry/.env` 文件,改 `LLM_API_KEY` 那行。

**Q: 想清空重新来?**
界面上点「↺ 新行程」(会保留你的「下一次出发」清单)。

**Q: 数据存在哪?**
全在本机 `~/work/gotry/shell/gotry-state/` — 可见、可编辑、可删除。不上传。
