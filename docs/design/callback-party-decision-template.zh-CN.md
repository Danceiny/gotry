## 速览（TL;DR）

- 接缝自身的规则继续有效：真实 callback 方出现前远程面保持关闭；本模板就是那一天要填的东西。
- 三个待决：通道形态（§2）、签名/通道绑定（§3）、token 归属（§4）——各带选项、运维成本与威胁面，均未选。
- sensor 来源按边界与证据选择（§5）——公开 registry、可识别 owner、可评审产物、有限爆炸半径——绝不认消息里出现的词，与仓内事故分类学的判据哲学一致。
- §6 的红线无论选哪个都成立：事件是事实不是指令；无写入；无 push；无常驻监听。

## 1. 范围与触发

- 接缝决策点：本地生产者免鉴权；world2agent 远程 callback 需要签名/通道绑定——等第一个真实 callback 方出现再拍，不预设。
- 已批纯契约切片（2026-09-12，issue #432）不受影响：惰性、默认关、精确四元组适配器，「claims 不是鉴权」。
- 只有真实 callback 方存在时，本文档才成为活的决策材料；在那之前它只记录选项，不记录决策。

## 2. 通道形态选项

| 形态 | 怎么跑 | 运维成本 | 威胁面 | 当前适配 |
|---|---|---|---|---|
| 本地桥 | sensor → 本地 webhook → owner 机器 supervisor → gotry hook（W2A 三个参考运行时的共同形态） | owner 机器上一个 opt-in 本地进程 | 信任边界在 sensor 供应链，不在传输层 | 单机形态的天然适配 |
| 远程 callback | gotry 暴露公网 endpoint 接收签名事件 | 公网暴露、秘密生命周期、可用性 | 传输鉴权变成必答题；接缝 §4 无常驻监听边界必须复审 | 与当前边界相抵触；随多用户形态（D-15）再议 |
| 拉取探针 | gotry tick 直读数据源，无 callback | 每个源一个探针 | 传输面最小 | 无桥环境的回退；失去 sensor 生态实时性 |

## 3. 签名/通道绑定选项（作用于远程形态）

| 选项 | 机制 | 运维成本 | 威胁面 |
|---|---|---|---|
| HMAC 作用域令牌 | 每方一个 secret，对作用域受限的负载签名（允许的事件类型加通道加时间戳加 nonce） | secret 签发、轮换、吊销台账；重放窗口的时钟纪律 | 共享秘密泄漏即可伪造事件直至轮换；占有即全部身份证明；nonce 纪律一松，重放抵抗最弱 |
| mTLS | 每方互信 TLS 客户端证书 | 证书机构、签发、到期、轮换；每方证书卫生 | 身份绑定最强（不可导出私钥）；运维失败即停摆；多接入方出现前是杀鸡用牛刀 |
| OAuth | 授权服务器发 token（client-credentials 流） | 运行并保护好第三信任方（AS） | token 被盗与重放；AS 成为新攻击面与新依赖 |

- 对比轴：当前单用户本地产品里运维成本占主导——AS 或 CA 都是接缝明确拒绝的常驻系统（§4 无常驻监听）；HMAC 作用域令牌仍是最轻的远程选项，三者此处均不选。
- 无论选哪个，接缝的绑定要求不变：签名把事件绑定到已评审的 来源/通道/类型 作用域；绝不因此把 payload 里的声明升格为事实。

## 4. token 归属选项

| 选项 | 谁持有什么 | 轮换负担 | 被攻破的爆炸半径 |
|---|---|---|---|
| founder 签发的每方 secret | gotry 侧签发与吊销；callback 方持有 secret | founder 侧轮换台账 | 一方泄漏只能伪造该方作用域内的事件 |
| 供应方持钥，gotry 钉验签材料 | sensor 供应方持钥；gotry 已评审注册表四元组携带公开验签材料 | 供应方轮换；换钥触发四元组复审 | 延续已批四元组白名单纪律 |
| 本地桥持有 token | owner 机器的桥持有 token（W2A hooks.token 形态）；远程方永不持有 gotry 凭据 | owner 侧，一台机器 | 远程被攻破碰不到 gotry；sensor 供应链成为全部边界 |

- 任何选项都未选；选项集的存在只是让第一天的决策有可比的菜单。

## 5. sensor 来源选择判据（边界与证据，不认词）

仓内分类学哲学以边界与证据为准：传输失败绝不落负面事实；exit0 不等于成功；「看起来对」不算数；sender/source 字段是不可信声明，四元组匹配不是鉴权。sensor 来源用同一哲学评判：

- 边界判据（全部必备）：经公开 registry 分发、产物版本不可变；owner/维护者可识别、安全联系方式可达；源码与 schema 可查，已评审四元组可在仓内核验；最坏爆炸半径限于健康面投毒——事实而非指令——且自然过期。
- 证据判据（全部留档）：已评审的 source/package/version/type 四元组；每个来源的出处与 integrity digest；漂移让闸变红而不是静默失败。
- 非判据（明确零权重）：payload 或包描述里出现的词（「official」「trusted」「verified」）；自报 sender 身份；没有立刻报错。

## 6. 无论怎么选都成立的红线

- 事件降级为事实，绝不是指令：只可进健康面与愿望池召回上下文，绝不进 turn-policy 分类器（ADR-24），绝不触发写动作（M5 WriteGate 红线）。
- M5 前无 push；单机形态无常驻监听；无环境变量产品开关。
- 无法核验的事件 fail closed：拒绝是稳定的，不存在部分信任。

- 无远程监听、无 token 签发、无远程方注册表、无消费者注册——全部等第一个真实 callback 方加 D-31 拍板。
- 今天不变：本地探针、愿望池消费、惰性纯契约适配器（§1）按既有批准继续运行。
