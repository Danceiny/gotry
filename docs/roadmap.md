2. A runtime cordis patch with by-id dual overrides (agent-default-model for the default model + a single llm-deepseek directory entry, without hardcoding upstream `DEFAULT_MODELS`).

Default-path protection: without `LLM_MODEL` neither track acts, and `.env.example`'s default line is commented out. The E2E `ts/scripts/model-override-e2e.ts` covers four scenarios (mock relay + isolated `DSH_HOME` + clean-tarball install form, including the "same settings, only env differs" control) — all green; the script now requires an explicit installed-package bin instead of faking package mode by moving source dependencies; smoke §17.
