## 里程碑详情

### M1:Agent 形态成立(← 当前)
- **Entry**:✅ 统一模型、契约草案、mock 垂直切片、异步闭环、真 LLM 适配器(全部完成)。
- **剩余三步**:① 创始人走查 S1 契约(三走查点:Gate 只允许选择题/workWindow 必带 evidence/assumptions 三分类);② 配置 DEEPSEEK_API_KEY;③ 跑 `npx tsx scripts/replay-real.ts` 对照 mock 检查质量——**key 到位后零新增代码**。
- **Exit(= Kimi 复盘的验收标准)**:同一份开场白,真人用户一句自然语言进、对话级已验证规划出,全程无人代劳翻译;零日历错误、零完全重排。
- **不许做**:真实供应链、UI 工程、B2B。

### M2:实时数据
- **Entry**:M1 exit + 供应链选型(机票数据源决策;酒店=hotelbyte-cli import+extend)。
- **交付**:capability-hotelbe 插件、航班数据桥;静态包退役为测试夹具(ADR-6 兑现)。
- **Exit**:同一 JourneySpec 实时 vs 静态的求解差异可度量、可归因。

### M3:最小可用产品(产品里程碑与商业 gate 交汇点)
- **Entry**:M2 exit + **G1 市场锁定**(中国出境/国内深度/全球英文——总纲 B1 决策包素材已齐,等你拍板)。
- **交付**:最小 Web 面(透明卡片+动机访谈+gates 的可体验形态,D-4 清偿);种子用户 50-200 人邀请制。
- **Exit**:种子用户行程定稿率 ≥40%、NPS ≥40、POI 幻觉 <1%(评测三件套全绿)。

### M4:记忆与「下一次出发」
- **Entry**:M3 exit。**交付**:C 端记忆域(六层框架重设计)、主动回访(可关闭)、北极星开始度量;对账七题答案=红眼模型与偏好的首批校准样本。
- **Exit**:回访用户规划时长较首访降 ≥50%;经验回流率有基线。

### M5:交易闭环
- **Entry**:M4 exit + 供应链协议。**交付**:WriteGate 生产化、预订/支付/退改、佣金披露(红线随行)。
- **Exit**:预订零误操作事故;单位经济实测(对齐 D1 §8)。

### M6:B2B 包裹
- **Entry**:M5 exit + P6 推演确认。**交付**:principal/sponsor 分离插件化,一个 B2B 场景(旅行社嵌入)零内核改动跑通。
- **Exit**:「99% 复用」实测数字;B2B 试点签约。

## 最短路径:现在 → M1 exit

```
你:契约走查意见(或「通过」)          ← 半小时量级
你:DEEPSEEK_API_KEY 配置              ← 一次环境变量
跑:cd ts && npx tsx scripts/replay-real.ts   ← 若走查有改,先回补契约(一次提交)
过:输出质量 ≥ mock 重放 → M1 exit,直接进 M2
```
